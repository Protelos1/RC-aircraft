# RC-aircraft
This is an Rc plane bassed on a fixed wing general aviation style aircraft! Hopefully a project that can help infulence and guide other people creating rc/aviation based projects.


Features:
---------
- Manuvers well in the air
- Easy to maintain and fix
- Parachute system for emergencies with easy deployment
- Made out of cheap and durable foamboard
- Durable to survive rough landings and small scuffs
